# 用自己的网盘备份 Life Atlas

Windows 桌面版可以把完整的 `.lifeatlas` 备份交给 OneDrive 或 Google Drive 的桌面客户端同步。文件保存在你自己的网盘，项目方无需购买存储服务器。这个流程与 Notability 的自动备份类似。另一台设备需要恢复时，下载并导入你选定的那一份快照。[Notability 自动备份说明](https://support.gingerlabs.com/en-us/articles/16300117-auto-backup-third-party-backup-guide)

## 第一次设置

1. 在电脑上登录自己使用的网盘客户端。在 OneDrive 的本地目录里创建 `Life Atlas 备份/我的笔记本`。使用 Google Drive for desktop 时，在普通本地磁盘创建同名目录，再在客户端首选项中将该文件夹添加到「与 Google 云端硬盘同步」。每台电脑各用一个子目录。[OneDrive 桌面同步](https://support.microsoft.com/en-us/onedrive/sync-your-computer-s-files-and-folders-with-onedrive) · [Google Drive 桌面同步](https://support.google.com/drive/answer/13401938)
2. 在 Life Atlas 的「工作区菜单 → 备份与恢复 → 定期备份」启用计划。选刚建好的、位于工作区数据目录以外的本地可写文件夹，选择每周时间和保留份数。应用运行时执行计划。希望立即传一份时，到「完整备份」导出至同一目录。
3. 建议勾选「加密整个备份」，另行妥善保管备份密码。需要带走密钥库时，还要勾选「包含密钥库」并按界面确认。恢复时，整包密码打开备份，原密钥库主密码或恢复密钥解锁密钥库。
4. Life Atlas 会校验备份并报告本地写入结果。等网盘客户端显示同步完成，再从网盘网页或另一台电脑检查文件名和大小。做一次恢复演练时，在另一套空白工作区里下载文件、校验、恢复，再打开一页笔记和一个附件确认内容。

**只同步完成的备份文件。** 保持正在使用的 SQLite 工作区、密钥库和附件数据目录在本机。Google Drive 的虚拟盘、仅在线占位文件或 Windows 目录链接可能无法通过本地路径校验。此时可让网盘客户端同步一个普通本地文件夹，或手动上传导出的备份。恢复前先使文件完整可在本机读取。

**空间按每份完整副本计算。** 例如每份 300 MB、保留 4 份，稳定占用约 1.2 GB。生成下一份和云端回收站可能暂时占用额外空间。每台设备单独设保留份数。超额、断网或网盘暂停期间，本地可以写入成功，远端仍可能没有新副本。

## 谁付费

| 路径 | 项目方 | 使用者 |
| --- | --- | --- |
| OneDrive 桌面同步 | 无 Life Atlas API 调用和存储账单 | 免费微软账号提供 5 GB 共享云空间。使用已有订阅容量也可以。[微软容量说明](https://support.microsoft.com/en-us/onedrive/microsoft-storage-faqs) |
| Google Drive 桌面同步 | 无 Life Atlas API 调用和存储账单 | 个人账号最多有 15 GB 免费空间，Drive、Gmail 和 Photos 等共用。容量不足时可减少保留份数或自选扩容。[Google 容量说明](https://support.google.com/accounts/answer/6374270) |

## 应用内直连的后续设计

**OneDrive 可以优先做。** 设计为默认关闭，用户按「连接 OneDrive」后走系统浏览器 OAuth 授权码与 PKCE，桌面程序使用公开客户端身份。在主进程以用户委托方式申请 `Files.ReadWrite.AppFolder`，只访问该应用文件夹。令牌用操作系统保护，用户可以断开授权。先支持个人账号，单位或学校账号单独验证租户策略。Microsoft Graph 普通 OneDrive 文件传输未列入按次收费清单，仍受用户容量和服务限流限制。[应用文件夹](https://learn.microsoft.com/en-us/graph/onedrive-sharepoint-appfolder) · [授权码与 PKCE](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow) · [Graph 计费清单](https://learn.microsoft.com/en-us/graph/metered-api-list)

应用先完成并校验本地加密备份，再把文件加入待上传队列。每份带设备标识和唯一版本。断网保留本地文件并重试，大文件使用可恢复上传。界面分别显示「本机已保存」「正在上传」「云端已确认」和需要用户处理的空间或授权问题。拿到远端文件记录并核对大小后才轮换同设备的旧云备份；下载恢复还要通过现有的整包校验。正式接入前要用测试账号验证中断续传、撤销授权、云盘已满以及从空工作区恢复。[可恢复上传](https://learn.microsoft.com/en-us/graph/api/driveitem-createuploadsession?view=graph-rest-1.0)

**Google Drive 直连备份需要 Google 事先明确书面同意。** Drive API 条款把开发者将自己应用里的用户内容或应用内容备份到 Drive 单独列出。用户同意 OAuth 或选择较窄的 `drive.file` 权限不能代替这一许可。取得许可后，再安排桌面 OAuth、应用发布核验、用户自有文件和恢复测试。当前可用路径是用户自行设置的桌面客户端同步或手动上传。[Drive API 条款](https://developers.google.com/workspace/drive/api/terms) · [Google OAuth 权限说明](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

截至 2026 年 11 月 25 日，Google 公布的 Drive REST API Standard Tier 免费，超出配额会限流。主动开通 Scaled Tier 后，自 2027 年 4 月 1 日起，超过各计费桶每日免费额度的 REST 调用可能产生开发者账单。上表的桌面同步方案不调用此 API。[Google Workspace API 配额和计费时间表](https://developers.google.com/workspace/guides/quota-usage-tiers)
