# 12 视觉规范：墨白（贴近 Notion）

用户在 2026-11-01 选定了“墨白”作为 Life Atlas 的界面风格，要白天和夜间两种模式；2026-11-06 又要求**样式和使用体验尽量贴近 Notion**（`01` 的 D-28）。所以“墨白”现在指的就是这套贴近 Notion 的样式：系统无衬线字体、暖灰文字、浅灰细线、一种蓝色强调色、柔和的浮层阴影、悬停才出现的控件。这份文件规定它长什么样；**所有界面都按这里和 `design/mobai/` 里的效果图做**，不要自己发明新样式。规格没写到的小细节，先想“Notion 在这里是怎么做的”，再选和效果图最接近的做法，写进报告第 5 节。

不要使用 Notion 的标志、插画、图标或任何代码：只学它的版式、颜色、间距和交互。图标一律用项目已有的 Tabler Icons（MIT）。

## 1. 一句话和六条原则

像 Notion：内容是主角，界面安静、紧凑、熟悉；用过 Notion 的人不用学就会用。

1. **安静的颜色，一种蓝。** 白底（夜间 `#191919`），暖灰色文字，浅灰细线。强调色只有 Notion 蓝 `#2383e2`：主按钮、勾选后的复选框、开关、选中的卡片、焦点光圈、进度条。用户自己选的颜色（标签、文字颜色、区块背景）用第 3 节的 9 种颜色。
2. **只用无衬线字体。** 标题、正文、界面文字都是 `--mb-sans`（Segoe UI + 思源黑体）；层级靠字号和字重（页面标题 40 px 700，区块标题 600）。衬线和等宽只在用户把页面字体改成“衬线 / 等宽”时用。
3. **控件悬停才出现。** 拖动手柄、区块左边的“+ ⋮⋮”、行尾的“···”、改日期的小按钮、同步区块的外框，平时看不见，鼠标移上去才出现。隐藏一律用 `opacity`（测试照样能找到和点击），不用 `display: none`。
4. **浮起来的才有阴影。** 菜单、弹出层、对话框、看板和画廊的卡片用 Notion 那种“一圈极淡的线 + 两层柔和阴影”；页面、侧栏、表格没有阴影。表格是浅灰网格线（横线和竖线都有）。
5. **悬停和选中都是一层淡灰。** 侧栏行、菜单行、列表行：悬停 `--mb-hover`，选中 `--mb-select`；不用左边竖线、不用加粗来表示选中。
6. **白天和夜间是同一套结构。** 只换颜色变量，不换布局、不换字号。

## 2. 主题结构（给以后留的位置）

- `<html>` 上两个属性：`data-style`（风格）和 `data-theme`（模式）。现在 `data-style` 只有 `"mobai"`；`data-theme` 是 `"light"` 或 `"dark"`。
- 所有墨白规则都写成 `:root[data-style="mobai"] …`。以后加第二套风格时：新建 `src/ui/themes/<名字>/`，规则写成 `:root[data-style="<名字>"] …`，在设置里多一个选项，**不需要改墨白的任何文件**。
- 颜色先变成变量（WP-20 用 `theme-tokens.mjs` 把旧 CSS 里写死的颜色全部换成 `--la-*` 变量），再由主题文件给变量赋值。产品代码里不准再写死颜色（wp-check 的 K13 从 WP-20 起检查；`src/ui/themes/` 是给变量赋值的地方，不在检查范围内）。
- 主题文件也修了两处被旧样式表覆盖的布局：画廊卡片（`styles.css` 里旧的三行网格把标题压在属性上）、时间线视图（旧规则把所有行排成一横排）。这是 `database.css` 里的规则，不需要改代码。
- 密钥库窗口（WP-07）和首次启动向导（WP-05）是单独的页面，不加载工作区的 CSS：它们按第 3 节的颜色自己写一份小样式表，用 `@media (prefers-color-scheme: dark)` 切换白天/夜间。主进程按用户的偏好设置 `nativeTheme.themeSource`（WP-20），这两个窗口就会自动跟着变。

## 4. 字体

| 角色 | 字体 | 大小 / 行高 / 字重 |
| --- | --- | --- |
| 页面标题 | `--mb-sans` | 40 px / 1.2 / 700 |
| 区块标题 1–3 | `--mb-sans` | 30 / 24 / 20 px，600，行高 1.3 |
| 正文 | `--mb-sans` | 16 px / 1.5 / 400；加粗 600 |
| 界面文字 | `--mb-sans` | 14 px（侧栏、菜单、表格、按钮）；12 px（分组标题、计数、提示） |
| 对话框标题 | `--mb-sans` | 16 px / 1.3 / 600 |
| 引用 | `--mb-sans` | 1.2 倍正文 / 1.5，左边 3 px 竖线 |
| 代码、密码、恢复密钥 | `--mb-mono`（Cascadia Mono，系统自带） | 代码块 13.6 px / 1.6；行内代码 0.85 倍 |

- `--mb-sans` 是 `"Segoe UI Variable Text", "Segoe UI", …, "Noto Sans SC Variable", …`：英文和数字用 Windows 自带的 Segoe UI，中文用打包的思源黑体（`@fontsource-variable/noto-sans-sc@5.3.1`）。`--mb-serif` 是 Georgia + 思源宋体（`@fontsource-variable/noto-serif-sc@5.3.1`），只给“衬线”页面字体用（时间脉络的导出图也是无衬线，WP-09 步骤 9）。两个字体包都是 OFL-1.1，按字符范围分片，只加载用到的分片。
- 数字列（日期、计数、百分比）用 `font-variant-numeric: tabular-nums`。
- 页面的“字体”设置（默认 / 衬线 / 等宽，页面菜单里的三个“Ag”按钮）：默认 = `--mb-sans`；衬线 = 标题和正文都用 `--mb-serif`；等宽 = `--mb-mono`。

## 5. 间距、圆角、线

- 页面正文栏宽 708 px（窗口小于 1100 px 时 680 px），页面图标 78 px，没有封面时标题区上方 64 px；封面高度 `clamp(200px, 30vh, 280px)`。这些都是主题给产品的 `--page-*` 变量赋的值。
- 区块之间：每个区块上下各 3 px 内边距；区块标题上方多 1 em。
- 圆角 4 种：3 px（标签、行内代码）、6 px（按钮、输入框、菜单行、侧栏行）、10 px（菜单、弹出层、卡片）、12 px（对话框、窗口）。代码块、标注、表格区块 4 px。
- 线：细线 1 px `--mb-line`；次按钮描边 1 px `--mb-line-2`。

## 10. 动效

- 时长：悬停 120 ms；展开/收起 160 ms；对话框出现 150 ms 淡入；锁孔圆盘解锁 700 ms。缓动 `ease` 或 `cubic-bezier(.7, 0, .3, 1)`。
- 没有自己动起来的装饰动画（光标闪烁除外）。`prefers-reduced-motion: reduce` 时全部动效时长变成接近 0。

## 11. 验收方法

- 截图一律 1440×900，白天和夜间各一张。
- 新界面：把截图和 `shots/` 里对应画面并排放，检查布局、字体（全部无衬线，标题粗体）、颜色（灰阶 + Notion 蓝，用户内容颜色除外）、线条（网格表格）、间距是否一致；再问一句“Notion 里这个地方是这样吗”。
- 机械检查（浏览器场景里用 `getComputedStyle`）：页面标题的 `font-family` 以 `"Segoe UI Variable Text"` 开头、`font-size` 是 `40px`、`font-weight` 是 `700`；白天页面底色 `rgb(255, 255, 255)`、侧栏 `rgb(247, 247, 245)`、正文颜色 `rgb(55, 53, 47)`；夜间页面底色 `rgb(25, 25, 25)`、侧栏 `rgb(32, 32, 32)`。
- 总设计师验收时会看并排对照图，不一致的地方开返工清单。
