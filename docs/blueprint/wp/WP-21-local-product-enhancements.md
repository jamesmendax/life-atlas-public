# WP-21 · Life Atlas 1.6.0 功能完善

## 目标与交付

完善 Life Atlas 的本地编辑、数据库和导航体验，借鉴适合本地实现的工作区交互。所有功能采用本机数据模型，在同一个 Windows x64 的 1.6.0 版本交付。

## 数据与模块接口

- `App` 统一提交工作区变化；schema、归档、库历史与依赖规则位于领域模块中。`databaseVersions` 属于完整备份集合。
- 编辑器提供 `getViewState/restoreViewState` 保存选区与滚动；页面演示通过 `onPresent` 打开只读快照。
- 设备偏好使用 `readDevicePreferences/updateDevicePreferences/subscribeDevicePreferences`，不进入工作区备份。视图标签字段为 `databaseViewTabDisplay`，对比度字段为 `contrast`。
- 行内数据库以 `sourceIdsJson` 声明数据源，整页数据库使用 `databaseSourceIds`。每个视图仍由自身 `sourceId` 路由读写。
- 记录布局经 `runtime.updateDataSourceLayout` 写入数据源，跨库视图由 `runtime.renderRecordLayoutView` 只读呈现。

## 验证与工程约束

采用既有回归和针对实际行为的功能测试；保留冻结兼容样本，并验证保存重开、旧版迁移、完整备份恢复和相关 Windows 入口。受影响的功能必须通过，缺少输入或环境的用例须明确记录验证边界。

数据结构和业务规则采用统一的新规则；旧数据需迁移时一并转换。完整备份保留各集合的原始顺序，恢复前先校验附件及跨源引用，避免半次恢复。
